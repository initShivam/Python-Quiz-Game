# 🧠 Quiz Game (True/False)

This is a simple command-line quiz game built using Python. The game presents a series of true/false questions, checks your answers, and keeps track of your score.

## 📌 Features

- Asks a series of True/False questions
- Validates user answers
- Provides instant feedback
- Tracks and displays the final score

## 🗂️ Project Structure

quiz-game/
├── main.py               # Main script to run the quiz
├── data.py               # Contains the list of quiz questions
├── README.md             # Project documentation (this file)

## 🚀 How to Run

1. **Clone the repository** or download the files.
2. Make sure you have Python installed.
3. Run the quiz using:

```bash
python main.py
```

4. Answer each question with `True` or `False` in the console.
